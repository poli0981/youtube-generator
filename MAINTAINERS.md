## Maintainer Responsibilities

- Triage incoming issues and PRs.
- Run the release process: `CHANGELOG.md` entry, version bump, build artifacts, signed tag.
- Enforce the [Code of Conduct](./CODE_OF_CONDUCT.md).
- Review and approve locale translation contributions.
- Coordinate security advisory disclosure per [SECURITY.md](./SECURITY.md).

## Becoming a Maintainer

There is currently no formal pathway. The project has been solo since inception. If you'd like to help maintain a specific area — most realistically, native-speaker review for one of the AI-translated locales (JA / ES / KO / ZH) — open an issue describing what you'd like to take on.

Persistent, high-quality contributions over time are the path. There is no application form.

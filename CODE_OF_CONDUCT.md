# Code of Conduct

This project adopts the **[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** in full.

By participating in this project — opening issues, submitting pull requests, commenting, translating locales, or any other form of contribution — you agree to abide by its terms.

## Reporting

Report violations privately to the maintainer: `lopop05905@proton.me`.

All reports are reviewed and investigated promptly and fairly. The maintainer is obligated to respect the privacy and security of the reporter.

## Enforcement

Examples of enforcement actions, in escalating order:

1. A private warning.
2. A public warning on the relevant issue / PR.
3. A temporary ban from contributing.
4. A permanent ban — applied without warning for serious violations (harassment, threats, malicious code submissions per [`CONTRIBUTING.md`](./CONTRIBUTING.md) auto-ignore rules).

For the full list of enforcement guidelines, read the [Contributor Covenant v2.1 — Enforcement Section](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement).

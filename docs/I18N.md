# Internationalization Guide (i18n)

## YTDescGen — Adding & Managing Languages

---

## Overview

YTDescGen has **two independent language contexts**:

1. **UI Language** — The app interface (buttons, labels, tooltips). Controlled by `SettingsStore.defaultLanguage`. Affects how the app *looks*.
2. **Output Language** — The generated title/description/tags. Controlled by `EditorStore.language`. Affects what the app *produces*.

These are independent: a Vietnamese user can browse the app in Vietnamese (UI) while generating descriptions in Japanese (output).

## File Structure

```
src/i18n/
├── index.ts                # i18next initialization + language registration
├── locales/
│   ├── _schema.json        # JSON Schema defining all required keys
│   ├── en/
│   │   ├── ui.json          # UI strings (buttons, labels, errors, tooltips)
│   │   └── templates.json   # Generated content (title, description patterns)
│   ├── vi/
│   │   ├── ui.json
│   │   └── templates.json
│   ├── ja/
│   │   ├── ui.json
│   │   └── templates.json
│   └── es/                  # Example: adding Spanish
│       ├── ui.json
│       └── templates.json
```

## Adding a New Language — Checklist

### Step 1: Create locale files

```bash
# Generate empty locale from schema
npm run generate:locale -- --lang es

# This creates:
# src/i18n/locales/es/ui.json       (all keys, empty values)
# src/i18n/locales/es/templates.json (all keys, empty values)
```

Or copy from English and translate:

```bash
cp -r src/i18n/locales/en src/i18n/locales/es
```

### Step 4: Register the language

```typescript
// src/i18n/index.ts — add to SUPPORTED_LANGUAGES
export const SUPPORTED_LANGUAGES = [
  { id: "en", label: "English", flag: "🇬🇧", nativeName: "English" },
  { id: "vi", label: "Vietnamese", flag: "🇻🇳", nativeName: "Tiếng Việt" },
  { id: "ja", label: "Japanese", flag: "🇯🇵", nativeName: "日本語" },
  { id: "es", label: "Spanish", flag: "🇪🇸", nativeName: "Español" },  // ← Add here
] as const;

// Add resource import
import esUI from "./locales/es/ui.json";
import esTemplates from "./locales/es/templates.json";

// Add to i18next resources
resources: {
  // ...existing
  es: { ui: esUI, templates: esTemplates },
}
```

### Step 5: Add multilingual tag pool

```typescript
// src/engine/tag-generator.ts — add to MULTILINGUAL_TAG_POOLS
multilingual_es: (gameName: string) => [
  `${gameName} sin comentarios`,
  `${gameName} gameplay completo`,
  `juego sin comentarios`,
],
```

### Step 6: Validate

```bash
npm run validate:locales
# Checks all locale files have the same keys as _schema.json
# Reports missing/extra keys per language
```

### Step 7: Test

```bash
npm run test -- --grep "i18n"
# Runs i18n-related tests including new language
```

## Template Interpolation

Templates use `{{variable}}` syntax (i18next default):

```json
"intro": "This video features the full gameplay of {{gameName}} on {{channelName}}."
```

Engine passes variables:
```typescript
t("templates:description.intro.full", {
  gameName: state.gameName,
  channelName: state.channelName,
});
```

## RTL Language Support (Arabic)

For Arabic (`ar`), add RTL handling:

```typescript
// src/i18n/index.ts
export const RTL_LANGUAGES = ["ar"] as const;

// src/App.tsx — set dir attribute
const isRTL = RTL_LANGUAGES.includes(currentLanguage);
<div dir={isRTL ? "rtl" : "ltr"}>
```

## Contributing Translations

Community members can contribute translations by:

1. Fork the repository
2. Copy `src/i18n/locales/en/` to `src/i18n/locales/{code}/`
3. Translate all strings
4. Run `npm run validate:locales` to check completeness
5. Submit a PR with the new locale files
